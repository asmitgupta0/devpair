# DevPair Product Requirements

## Problem

Students practise coding problems alone but technical interviews often require live collaboration in a shared editor.

## Target user

Two CS students preparing for coding interviews.

## Core user flow

1. A user creates a room.
2. DevPair creates a shareable URL.
3. A second user opens the URL.
4. Both users write code in real time.
5. Users can later run code and request hints.

## First milestone

Two users can open the same room in separate browsers and see code updates without refreshing.

## Not included in Version 1

- Video call
- Chat system
- Multiple files
- File uploads
- Collaborative CRDT editing
- Problem library
- Payments
