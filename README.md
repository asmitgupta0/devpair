# DevPair

A real-time collaborative code editor for interview preparation.

## Why DevPair?

Technical interviews often use shared coding editors, but students usually practise alone.
DevPair lets two users open a shared room, write code together, execute solutions, and request context-aware interview hints.

## Planned stack

- React + TypeScript
- Node.js + Express
- Socket.io
- MongoDB
- Monaco Editor
- Judge0
- Groq
- Vercel + Railway

## Current status

Project setup completed. Real-time room collaboration is the next milestone.
